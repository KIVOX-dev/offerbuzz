# Home page banner photos

Drop wide banner photos here. The sliding banners on the home page use them automatically (no code change). If a file
is missing, that slide falls back to the small category picture.

| File | Slide |
|---|---|
| `fashion.webp` | Festive fashion sale |
| `electronics.webp` | Latest gadgets, best prices |
| `grocery.webp` | Fresh groceries, daily savings |
| `travel.webp` | Weekend getaway packages |

Size: 1600 x 640 px (5:2), WebP or JPG renamed to the names above, under 200 KB each.
Keep the subject on the RIGHT 45% of the picture and leave the left half calm and empty: the headline and button sit there.
